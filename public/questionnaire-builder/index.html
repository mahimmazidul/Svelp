Open Svelp

A questionnaire builder for research workflows

Svelp gives researchers two ways to author questionnaires: a visual builder for point-and-click editing, and Source Mode — a plain-text language that compiles into the same questionnaire. Both stay in sync, and both produce print-ready, scanner-safe forms.

Visual builder

Add sections and questions, reorder them, edit options and validation, and preview the questionnaire as respondents will see it.

Source Mode

Prefer text? Describe the whole questionnaire in the declarative svelp 1 language. The editor validates as you type, explains every problem with a line number, and applies changes transactionally — invalid source never touches your questionnaire.

svelp 1

title "Household Survey"

scale frequency
  option never "Never" code 0
  option often "Often" code 1

section diet "Diet"

matrix staples "How often do you discard:"
  scale frequency
  rows {
    rice "Cooked rice"
    bread "Bread"
  }

Research-grade structure

  • All standard question types including matrix grids and Likert scales
  • Reusable scales shared across questions
  • Consent blocks with purpose, confidentiality, and acknowledgement sections
  • Participant and researcher signature blocks
  • Stable question identities: rename safely without breaking collected data
  • FFQ-style 60x7 matrices print cleanly in the Compact profile

Print ready by default

Every questionnaire prints as scanner-ready PDF with QR page identity and alignment markers. No separate design step.
