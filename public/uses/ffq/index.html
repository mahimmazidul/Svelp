Open Svelp

Food frequency questionnaires, without the data entry

A 60-item FFQ is hundreds of cells to key by hand. Svelp builds the matrix once, prints it as a compact scanner-ready table, reads the completed marks deterministically, and hands you a clean CSV.

FFQ workflows in Svelp

  • Matrix questions with large row sets (60+ foods) and shared frequency scales
  • Reusable scales: define "Never … With every meal" once, reuse it everywhere
  • Compact and Dense print profiles keep wide matrices on few pages
  • Scanner-ready tables with QR page identity and alignment markers
  • Batch scanning of completed questionnaires with review of uncertain marks
  • CSV export plus a codebook mapping codes to labels

Example source snippet

scale frequency
  option never "Never" code 0
  option sometimes "Sometimes" code 1
  option often "Often" code 2
  option daily "Daily" code 3

matrix staples "How often does your household eat:"
  scale frequency
  single_per_row
  rows {
    rice "Cooked rice"
    bread "Bread"
    vegetables "Fresh vegetables"
  }
