Likert scales, built once and reused

Svelp treats Likert batteries as first-class citizens: declare the response scale once, attach any number of statements, print compact tables, and scan completed pages with deterministic recognition.

Two ways to author

  • Inline points: declare 1–5 labels directly under one question
  • Reusable scale: declare once, reference from any Likert question or matrix
  • Source Mode makes twenty-statement batteries a copy-paste job
  • Compact printing fits long batteries on one page

Inline example

likert trust "I trust the process"
  1 "Strongly disagree"
  2 "Disagree"
  3 "Neutral"
  4 "Agree"
  5 "Strongly agree"
  required

Scanning Likert grids

Marked cells are read geometrically; ambiguous cells route to review with the surrounding row shown for context.
