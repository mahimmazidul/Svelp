What Svelp does

Everything below is implemented in the current Svelp build and runs entirely on your device.

Questionnaire building

  • Visual builder with sections, reorderable questions, and live preview
  • Source Mode: a plain-text questionnaire language (svelp 1) with syntax highlighting, validation, and one-click apply
  • Question types: single choice, multiple choice, yes/no, short and long text, number, date, time, Likert, matrix/grid, consent blocks, participant and researcher signatures
  • Reusable response scales shared across questions and matrices
  • Stable question identity: renaming keeps data linked; destructive changes require confirmation
  • Versioning: published questionnaires reopen as new drafts

Printing

  • Print-exact PDF output with alignment markers and a QR page identifier on every page
  • Comfortable, Compact, and Dense print profiles tuned for scanner-safe geometry
  • Bangla labels rendered with real Bengali shaping in PDFs
  • Batch printing with per-set respondent IDs

Scanning and review

  • Batch image and PDF import from any phone camera or flatbed scans
  • QR-based page identification with automatic template matching
  • Page normalization: rotation, perspective, and lighting corrected locally
  • Deterministic mark recognition — measured geometry, no AI
  • Uncertain, double-marked, and crossed-out answers routed to a review queue instead of guessed
  • Blank, intentional-blank, and unreadable states preserved

Data and portability

  • Response table with per-question review and corrections
  • CSV and JSON export with codebooks
  • MAHIM container format for moving projects between devices
  • Local storage tools: export, import, and measured storage usage
  • Offline-first PWA: install and keep working without a connection
  • Bangla questionnaire labels, options, and consent text supported end to end
